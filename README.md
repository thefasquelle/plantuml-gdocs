# plantuml-gdocs

Google Docs add-on to insert and modify PlantUML diagrams directly in the document.

# Features

- 100% client-side, everything is done in browser
- No data sent to another server
- Diagram source code is saved directly in document as the image's Alt Text
- Diagram source code is also saved as png metadata

# Planed features

- Support for Google Sheets
- Support for Google Slides
- Support for Google Drawings
